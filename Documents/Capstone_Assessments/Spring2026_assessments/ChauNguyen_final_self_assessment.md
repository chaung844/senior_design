My individual contribution to this project focused primarily on the backend. I worked on the matching algorithm to match receipts with bank statement lines, helped develop the database schema, set up the backend, and implemented several core functionalities. Through this project, I applied both skills from my coursework and experience gained during my co-op. Those experiences helped me think beyond individual features and consider the system as a whole, which was especially useful when we discussed how to implement the system on a larger scale.

Working on this senior design project also allowed me to explore tools and technologies I hadn’t used before, such as SQLAlchemy and AWS services like SQS and Bedrock. One challenge I faced was dealing with uncertainty in the requirements and implementation approach. Balancing abstraction and concrete decisions was difficult at first, but I learned that working through these uncertainties is an essential skill for engineers. A key success was designing and implementing a matching algorithm that balanced accuracy with confidence. We wanted to match as many receipts as possible, but also ensure that matches were reliable and followed the necessary rules, while involving humans in the loop when needed.
